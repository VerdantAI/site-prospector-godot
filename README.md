# Site Prospector

A Godot add-on that provides an opinionated AI workflow to generate game levels based on actual topologies, scaled to game size. Builds maps from real satellite data and allows quick enrichment for game purposes.

> **Note:** This add-on will be available on the [Godot Asset Store](https://store.godotengine.org/) once it reaches a stable release.

## Installation

1. Copy the `addons/site_prospector/` folder into your project's `addons/` directory.
2. Open your project in Godot.
3. Go to **Project → Project Settings → Plugins** and enable **Site Prospector**.
